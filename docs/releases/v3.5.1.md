# Vitul CLI 3.5.1

Changes since [v3.5.0](https://github.com/agentos-org/vitul/releases/tag/v3.5.0).

## Highlights

- New Vitul apps use `agentos-sdk-ts` `^2.4.0`, which adds NotifyKit notifications and HarnessKit tool policies. Existing `createAgentOSClient()` calls remain compatible.
- New projects generated by Vitul CLI and `create-vitul-app` depend on Vitul CLI `^3.5.1`.
- Remove the unused AndroidTone and WinTone example apps and update AgentOS feature guidance.

## npm package versions

| Package | Version |
| --- | ---: |
| `@litevar/vitul-cli` and its 11 native binding packages | `3.5.1` |
| `@litevar/vitul` | `0.5.1` |
| `create-vitul-app` | `0.5.1` |

The Rust preview CLI remains at `0.2.0`; the desktop runtime and JavaScript API retain the `2.12.0` source baseline. See the [version map](../MAINTENANCE.md).

## Migration

No changes are required for existing projects. The generated AgentOS SDK dependency update applies to newly created projects.

**Full changelog:** [v3.5.0...v3.5.1](https://github.com/agentos-org/vitul/compare/v3.5.0...v3.5.1).
