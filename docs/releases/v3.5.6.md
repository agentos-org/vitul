# Vitul CLI 3.5.6

## Highlights

- New apps use `agentos-sdk-ts` `^3.0.0`. The generated
  `createAgentOSClient()` helper keeps the same API.
- SDK 3.0 changes DiscoveryKit to device-level discovery. Use `getPeers()`
  or `streamPeers()` for nearby devices and `getSelf()` for the current device.
- Existing apps that upgrade the SDK should remove DiscoveryKit registration
  calls and send files with `targetDeviceId` instead of `targetBundleId`.
  The receiving device handles incoming files in its built-in nearby transfer
  UI. Apps can still list, track, and cancel their outgoing transfers.
  See the [SDK changelog](https://github.com/agentos-org/agentos-sdk-ts/blob/v3.0.0/CHANGELOG.md).
