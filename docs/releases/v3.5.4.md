# Vitul CLI 3.5.4

Changes since [v3.5.3](https://github.com/agentos-org/vitul/releases/tag/v3.5.3).

## Highlights

- New Vitul projects describe OpenTool 1.0.0 parameters using
  `parameters[].schema` and return values using `return.schema`. AgentOS
  Desktop's `opentool_dart` 3.0.0 parser can recognize both.
- Update the starter, AgentOS examples, and desktop API fixture to use the
  corrected schema structure. Existing RPC method names and behavior remain
  unchanged.
- Update vulnerable build and runtime dependencies and audit standalone
  project dependencies.

## Verification and migration

On macOS ARM64, the Vitul CLI tests passed. A freshly generated backend and the
starter backend were started locally; `/opentool/load` returned the corrected
schema and `greet` returned the expected response. The actual HTTP output was
also parsed and validated with `opentool_dart` 3.0.0.

Existing projects keep their own OpenTool descriptions. Update their backend
schemas separately; upgrading the CLI does not rewrite existing project files.
