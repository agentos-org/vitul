# Vitul CLI 3.5.5

Changes since [v3.5.4](https://github.com/agentos-org/vitul/releases/tag/v3.5.4).

## Highlights

- New Vitul apps use `agentos-sdk-ts` `^2.5.2`. HarnessKit can register an
  app's local OpenTool callback for a specific thread with
  `registerPrivateTools()`. ModelKit exposes optional benefit-card and billing
  metadata on `ModelInfo` when the Gateway provides it.

## npm package versions

| Package                                                 | Version |
| ------------------------------------------------------- | ------: |
| `@litevar/vitul-cli` and its 11 native binding packages | `3.5.5` |
| `@litevar/vitul`                                        | `0.5.5` |
| `create-vitul-app`                                      | `0.5.5` |

See the [version map](../MAINTENANCE.md) and [supported platforms](../SUPPORT.md).

Existing apps can update their own SDK dependency to `^2.5.2`.

**Full changelog:** [v3.5.4...v3.5.5](https://github.com/agentos-org/vitul/compare/v3.5.4...v3.5.5).
