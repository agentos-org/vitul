# 3.5.1 Release Preparation

Preparation date: 2026-11-04 (Asia/Singapore).

## Release versions

- JavaScript CLI and 11 platform binding packages: `3.5.1`.
- `@litevar/vitul` and `create-vitul-app`: `0.5.1`.
- New generated apps use `agentos-sdk-ts ^2.4.0` and Vitul CLI `^3.5.1`.
- Rust CLI `0.2.0`, desktop runtime/API `2.12.0`, and manifest schema `1` remain unchanged.

Before preparation, npm reported `@litevar/vitul-cli@3.5.0`,
`@litevar/vitul@0.5.0`, and `create-vitul-app@0.5.0` as the current releases.
The `v3.5.1` tag did not exist on GitHub.

## Changes since v3.5.0

- Upgrade generated app templates to AgentOS SDK `^2.4.0`.
- Remove the unused AndroidTone and WinTone examples.
- Update AgentOS feature guidance and generated CLI dependency defaults.

## Release workflow

1. Run the repository checks and review the release diff.
2. Commit the release preparation and push it to GitHub.
3. Create and push tag `v3.5.1`; create a GitHub Release using `v3.5.1.md`.
4. Run `publish-cli-js.yml` on the `v3.5.1` ref with the GitHub Release ID. The workflow builds and tests native bindings before publishing the CLI and platform packages to npm.
5. After confirming `@litevar/vitul-cli@3.5.1` is available from npm, run `publish-vitul-commands.yml` on the `v3.5.1` ref with package `all` to publish both `0.5.1` wrappers.
6. Confirm the three published npm versions and a clean generated app installation.

GitHub CLI authentication was unavailable during initial preparation; the
GitHub Release and workflow dispatch still need to be completed through a
connected GitHub session.
