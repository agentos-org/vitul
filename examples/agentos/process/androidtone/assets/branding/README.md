# AndroidTone logo source

`androidtone-logo.source.png` is an unchanged copy of the user-provided `~/Downloads/androidtone_logo.png` (1254 × 1254 RGB). The original composition already fills a square, so the robot and shopping bag are retained in full.

`androidtone-logo.cropped.png` preserves that framing, with only the near-black outer canvas connected to the image edge cropped to transparent pixels. Interior artwork is preserved. Exports use Lanczos resizing:

- `../../icon.png`: 512 × 512, AgentOS package icon.
- `../../frontend/public/icon.png`: 256 × 256, page header icon.
- `../../frontend/public/favicon.png`: 64 × 64, browser icon.

`androidtone-logo.previous.svg` preserves the earlier vector design for reference and is not included in the app package.

Vite copies the page assets into generated `public/` during each frontend build.
