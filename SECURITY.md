# Vitul Security Policy

[简体中文](SECURITY-zh_CN.md)

## Supported Versions

Vitul is pre-1.0. Only the latest published preview release is in scope for
security fixes, on a best-effort basis. After 1.0, see the
[maintenance policy](docs/MAINTENANCE.md) for the supported release line.

## Reporting a Vulnerability

Please do not publish a suspected vulnerability in a public issue, pull
request, chat, or forum post. If private vulnerability reporting is enabled
for this repository, submit a report through GitHub's private reporting
feature. Otherwise, use the private contact method published in the repository's
About section or on the maintainer's [@LiteVar GitHub profile](https://github.com/LiteVar)
and include the affected component, impact, and reproduction details.

The Vitul maintainers will triage reports and coordinate any fix and public
disclosure with the reporter. Vitul includes upstream dependencies; reports
may need to be coordinated with the maintainers of the affected dependency.
