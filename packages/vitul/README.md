# @litevar/vitul

The `vitul` command delegates to [`@litevar/vitul-cli`](https://www.npmjs.com/package/@litevar/vitul-cli).
Install it globally with `npm install --global @litevar/vitul`, or run commands
from a project that has `@litevar/vitul-cli` installed.

Create an application with `vitul create my-app`, then use `vitul dev` and
`vitul build --target agentos` from the project directory. New apps keep their
desktop, mobile, and AgentOS settings in the root `vitul.conf.json`.
